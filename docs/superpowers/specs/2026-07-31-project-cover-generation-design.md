# 项目独立封面生成设计

## 目标

项目首页的每张项目卡展示该项目专属封面，绝不把智能穿戴项目的封面作为其它项目的回退图。学习计划日历使用温暖日历插画；今后新增项目自动获得独立封面。

## 范围

- 保留智能穿戴监测系统现有科技封面。
- 为学习计划日历提供温暖日历风格的专属 SVG 封面。
- 在项目创建流程中自动生成并保存未来项目的 SVG 数据 URL 封面。
- 对缺少 `cover_image_url` 的已有或异常项目，在首页即时生成该项目专属封面。

不包含后台手动上传封面、外部图片生成服务或修改项目授权逻辑。

## 设计

### 封面生成器

新增纯函数模块 `src/project-cover.js`：输入项目的 `code`、`name` 和 `description`，输出稳定的 SVG 数据 URL。

- 使用项目代码的确定性散列选择配色、背景图形和短标签，保证同一项目在每次访问时的展示一致。
- SVG 对项目名称和描述进行 XML 转义；不嵌入外部资源。
- 学习计划项目使用固定的温暖日历构图：奶油与珊瑚色背景、纸张式日历、彩色课程块和 “LEARNING PLAN” 标签。
- 智能穿戴项目保持现有 `/assets/cyber-body-base.png`，不由生成器覆盖。

### 数据写入与首页渲染

项目初始化/创建时，如果项目不是智能穿戴且未提供封面，调用生成器并写入 `projects.cover_image_url`。项目首页以 `project.coverImageUrl || generateProjectCover(project)` 作为图片地址，不再出现智能穿戴封面的默认回退。

学习计划项目的初始化迁移/同步逻辑会更新其 `cover_image_url` 为生成器输出的专属日历封面。已授权项目仍由既有项目列表接口返回，权限过滤保持不变。

### 错误处理

SVG 生成不依赖网络或数据库调用。若项目数据为空，生成器使用安全的“项目”标签和中性描述，仍生成独立封面。首页在图片加载失败时隐藏破图并保留卡片内容，不替换为其它项目图片。

## 验证

- 单元测试验证同一项目的生成 URL 稳定、不同项目不会共享封面、SVG 已转义输入文本。
- 项目首页测试验证没有 `/assets/cyber-body-base.png` 回退逻辑，并保留智能穿戴项目自身封面。
- 项目初始化测试验证学习计划项目获得独立 `cover_image_url`。
- 运行完整 `npm test`，并检查首页在已登录和游客模式下的项目卡展示。

## 自检

- 无 TBD、TODO 或未决选项。
- 智能穿戴封面仅用于智能穿戴项目；学习计划与未来项目均有独立生成路径。
- 设计只涉及项目封面生成和首页展示，不改变项目授权、登录或学习计划数据。

# 学习计划自建人物设计

**日期：** 2026-07-26
**状态：** 已确认，待实现

## 目标

移除学习计划项目中固定的“大公主／小公主”人物。每个登录账号在自己的学习计划项目中创建并管理人物，计划、统计和日历均以这些人物为准。

## 数据迁移

- 新增 `study_people`，按 `user_id + project_id` 隔离，包含人物 ID、名称、颜色序号、创建与更新时间。
- 迁移先删除现有 `study_plans` 的全部记录；不保留或迁移“大公主／小公主”计划。
- 移除 `study_plans.student` 的固定取值约束，改为 `person_id` 外键；计划必须引用同一账号、同一项目的人物。
- 人物表初始为空，不创建任何默认人物。

## API 与人物规则

- 在既有学习计划项目 API 下新增人物的列表、创建、更新名称和删除接口；所有接口沿用登录及项目授权。
- 人物名称为 1–30 字的非空文本，同一账号、项目下不能重复。
- 只能删除没有任何学习计划引用的人物；有计划时返回明确错误，用户须先删除相关计划。
- 更新人物名称后，已有计划和日历立即显示新名称，因为计划仅保存人物 ID。
- 创建计划时使用 `personId`；服务端验证人物属于当前账号与项目，拒绝跨账号或跨项目的人物 ID。

## 界面

- 删除“大公主／小公主”标签、默认选项、固定图例和固定个人页签。
- 新增“人物”管理入口：可新增、改名、删除未使用人物；无人物时展示引导。
- 新增计划弹窗从当前人物库选择人物；若人物库为空，不允许保存计划，并引导先新增人物。
- 总览和日历显示全部人物；人物页签由人物库动态生成。人物按创建顺序循环使用预设颜色，支持两个以上人物。
- 人物与计划操作成功后，前端只采用服务端返回的数据更新状态；失败时不误显示为已同步。

## 验证

- 迁移后旧计划为零，人物库为空，且数据库不再有固定人物值约束。
- 人物与计划查询、修改和删除均按账号与项目隔离。
- 同账号可创建多个自定义人物；人物改名能更新历史计划的日历显示。
- 有关联计划的人物无法删除；删除计划后可以删除人物。
- 页面无固定人物文案；空人物库、动态人物切换、多人物颜色和同日按时间排序均可用。

## 非目标

- 不保留已有学习计划数据。
- 不支持人物头像、年龄、关系或共享人物库。
- 不支持人物删除时迁移其计划到其他人物。
